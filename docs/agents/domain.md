# Domain Docs

This repository uses a single domain context.

## Before exploring

- Read `GLOSSARY.md`.
- Read ADRs in `docs/adr/` that touch the area being changed.

## File structure

```text
/
├── GLOSSARY.md
├── docs/adr/
└── src/
```

The `/domain-modeling` skill creates additional glossary terms or ADRs when decisions are resolved. Do not create speculative domain documents.
