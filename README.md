# 流光（Lumi）

Windows 音乐控制中枢。通过系统媒体会话（SMTC）统一控制支持 Windows 媒体控制的音乐软件，并为网易云音乐提供无需登录的兼容控制层，同时提供低误触的桌面便捷条。

## 开发

```powershell
pnpm install
pnpm test
pnpm build
pnpm tauri dev
```

需要 Windows 10/11、WebView2、Rust stable 和 MSVC C++ Build Tools。

## 首版边界

- 不播放本地文件，不登录第三方账号。
- 其他音乐软件只支持正确发布 SMTC 会话的客户端；网易云音乐使用窗口元数据与本地音频状态作为兼容回退。
- 网易云兼容层支持标题、歌手、播放/暂停、上一首和下一首。时间轴优先 OCR 采样；采样不可用时按播放墙钟推进（以采样为锚点），暂停时冻结在暂停瞬间的位置；网易云回退不提供专辑封面。
- 进度与播放状态以「采样 + 墙钟」的连续时钟为准：暂停不会回退到上一次采样，恢复时从冻结位置继续。
- 播放控制命令执行后会立即向主窗口与便捷条同时广播快照，两个窗口不会再出现按钮状态错位。
- 暂不提供播放队列、收藏、搜索或历史记录。
- 应用为单实例运行；重复打开快捷方式只会唤起已有窗口。
- 歌词来源按 LRCLIB、LRCLIB 搜索、网易云公开歌词接口依次回退；查询失败时可导入本地 LRC。
- 快捷键可在设置中直接按键录入，冲突会在设置面板内提示。
- 开机启动使用当前用户注册表 Run 项，启动后直接显示主窗口。

## 使用

1. 在网易云音乐、Spotify 或 QQ 音乐等客户端中开始播放。
2. 打开流光，主窗口会自动列出可控制的媒体会话。
3. 便捷条默认锁定并鼠标穿透。按 `Ctrl+Alt+L` 临时解锁；光标进入过便捷条后离开会自动回锁，5 秒无操作也会回锁。
4. 按 `Ctrl+Alt+Q` 显示或隐藏便捷条；旧版默认的 `Ctrl+Alt+M` 会自动迁移。
5. 解锁后可使用原生输入桥控制播放，或拖动便捷条调整位置；点击控制不会切换到应用窗口。
6. 设置中的“歌词偏移”可修正网易云回退时间轴与歌词之间的偏差。

同步歌词来自 LRCLIB，并在本地缓存。匹配失败时可以在主窗口导入本地 `.lrc` 文件。

## 安装包

```powershell
pnpm package:installer          # 常规包，内嵌 WebView2 引导程序（约 5 MB）
pnpm package:installer:offline  # 离线包，内嵌完整 WebView2 运行时（约 130 MB，适合无网机器）
```

产物会自动收集到 `artifacts/流光_<version>_x64-setup.exe`。

已知限制：

- 安装包未签名，Windows 首次运行会显示 SmartScreen 提示（需要代码签名证书才能消除）。
- 常规包在缺少 WebView2 的机器上需要联网下载运行时；完全离线请用离线包。
- 安装目录由 NSIS 的 `$LOCALAPPDATA` 解析，若系统把该 shell 文件夹重定向到其它盘，安装位置会跟着走。应用启动时会校正开机启动项；桌面快捷方式若指向已不存在的旧路径，会自动改回当前可执行文件。

安装器通过 `src-tauri/installer-hooks.nsh` 在安装结束时重写卸载注册表项，保证「应用和功能」里的版本号与构建版本一致。
